Thực hành truy vấn SQL trên CSDL MyMusic

Viết 11 câu truy vấn trên CSDL quản lí nhạc sĩ – ca sĩ – bản nhạc – bản thu âm: từ chọn cột đơn giản đến nối 4 bảng. Mỗi câu có hướng dẫn giải và kết quả mong đợi.

1 Mục tiêu và chuẩn bị

Sau bài thực hành, em có thể:

  • Dùng SELECT … FROM … WHERE … để truy xuất dữ liệu từ một bảng.
  • Dùng toán tử LIKE với kí tự đại diện % để tìm theo mẫu.
  • Dùng JOIN … ON … để kết hợp dữ liệu từ 2, 3, 4 bảng liên kết bằng khoá ngoài.
  • Biết cách xác định bảng nào cần có trong câu truy vấn và nối chúng theo đúng khoá.

Cách làm:

  1. Mở HeidiSQL, kết nối máy chủ MySQL/MariaDB (như Bài 17–20), chọn CSDL mymusic ở khung bên trái.
  2. Mở thẻ Query (hoặc nhấn Ctrl+T để mở thẻ truy vấn mới), gõ câu lệnh SQL rồi bấm nút ▶ hoặc nhấn F9 để chạy.
  3. Kết quả hiện ở khung bên dưới. Em so sánh với bảng Kết quả mong đợi trong phần hướng dẫn giải.
💡

Hãy tự làm trước, xem lời giải sau. Mỗi câu có ô để em viết nháp câu lệnh. Chỉ mở phần Xem hướng dẫn giải khi đã thử ít nhất một lần.

2 Cơ sở dữ liệu MYMUSIC

CSDL MyMusic lưu thông tin về nhạc sĩ, ca sĩ, bản nhạc và các bản thu âm. Em đã tạo bốn bảng này ở Bài 19 và Bài 20; hôm nay em khai thác dữ liệu bằng câu lệnh SQL. Mỗi bản nhạc do một nhạc sĩ sáng tác; mỗi bản thu âm gắn một bản nhạc với một ca sĩ thể hiện (một bản nhạc có thể có nhiều bản thu âm, một ca sĩ có thể có nhiều bản thu âm).

2.1. Lược đồ quan hệ

Gạch chân là khoá chính, in nghiêng là khoá ngoài.

nhacsi (idNhacsi, tenNhacsi)
casi (idCasi, tenCasi)
bannhac (idBannhac, tenBannhac, idNhacsi, tenTheloai)
banthuam (idBanthuam, idBannhac, idCasi)

3 Tạo CSDL và nhập dữ liệu mẫu

Nếu em đã tạo CSDL mymusic và nhập dữ liệu ở các bài trước, em có thể bỏ qua phần này. Nếu chưa có (hoặc bảng bannhac của em chưa có cột tenTheloai), hãy chạy script dưới đây trong thẻ Query của HeidiSQL.

Xem script tạo bảng và nhập dữ liệu (bấm để mở)
SQL · mymusic.sql
-- Tạo CSDL mymusic và nhập dữ liệu mẫu (chạy trong thẻ Query của HeidiSQL)
CREATE DATABASE IF NOT EXISTS mymusic CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE mymusic;

DROP TABLE IF EXISTS banthuam;
DROP TABLE IF EXISTS bannhac;
DROP TABLE IF EXISTS casi;
DROP TABLE IF EXISTS nhacsi;

CREATE TABLE nhacsi (
  idNhacsi INT NOT NULL AUTO_INCREMENT,
  tenNhacsi VARCHAR(255) NOT NULL DEFAULT '',
  PRIMARY KEY (idNhacsi)
) ENGINE=InnoDB;

CREATE TABLE casi (
  idCasi INT NOT NULL AUTO_INCREMENT,
  tenCasi VARCHAR(255) NOT NULL DEFAULT '',
  PRIMARY KEY (idCasi)
) ENGINE=InnoDB;

CREATE TABLE bannhac (
  idBannhac INT NOT NULL AUTO_INCREMENT,
  tenBannhac VARCHAR(255) NOT NULL DEFAULT '',
  idNhacsi INT NOT NULL,
  tenTheloai VARCHAR(255) NOT NULL DEFAULT '',
  PRIMARY KEY (idBannhac),
  UNIQUE KEY uq_bannhac (tenBannhac, idNhacsi),
  CONSTRAINT FK_bannhac_nhacsi FOREIGN KEY (idNhacsi) REFERENCES nhacsi (idNhacsi)
) ENGINE=InnoDB;

CREATE TABLE banthuam (
  idBanthuam INT NOT NULL AUTO_INCREMENT,
  idBannhac INT NOT NULL,
  idCasi INT NOT NULL,
  PRIMARY KEY (idBanthuam),
  UNIQUE KEY uq_banthuam (idBannhac, idCasi),
  CONSTRAINT FK_banthuam_bannhac FOREIGN KEY (idBannhac) REFERENCES bannhac (idBannhac),
  CONSTRAINT FK_banthuam_casi FOREIGN KEY (idCasi) REFERENCES casi (idCasi)
) ENGINE=InnoDB;

4 Bài tập truy vấn dữ liệu

Em hãy viết các truy vấn sau. Viết các câu lệnh trong HeidiSQL, so sánh kết quả với đáp án.

Câu 1Chọn cột · 1 bảng

Truy xuất dữ liệu tên ca sĩ, mã định danh ca sĩ của bảng casi.

Bảng liên quan: casi

Xem hướng dẫn giải câu 1

Phân tích

  1. Đề yêu cầu hai cột: tenCasi rồi idCasi → liệt kê sau SELECT, đúng thứ tự đề bài.
  2. Dữ liệu lấy từ một bảng duy nhất casi → FROM casi.
  3. Đề không giới hạn ca sĩ nào → không cần WHERE.

Câu lệnh SQL

SQL
SELECT tenCasi, idCasi
FROM casi;

Câu 2Nối 3 bảng · lọc

Tìm những ca sĩ hát bản nhạc “Tiến về Hà Nội”.

Bảng liên quan: casi, banthuam, bannhac

Xem hướng dẫn giải câu 2

Phân tích

  1. Cần hiển thị tenCasi (bảng casi); điều kiện nằm ở tenBannhac (bảng bannhac).
  2. casi và bannhac không nối trực tiếp. Cầu nối là bảng banthuam (chứa cả idBannhac lẫn idCasi) → xuất phát từ banthuam.
  3. Hai điều kiện nối: bt.idBannhac = bn.idBannhac và bt.idCasi = cs.idCasi (khoá ngoài = khoá chính được tham chiếu).
  4. Lọc bằng WHERE bn.tenBannhac = 'Tiến về Hà Nội'. Em đặt bí danh bt, bn, cs cho ngắn gọn.

Câu lệnh SQL

SQL
SELECT cs.tenCasi
FROM banthuam bt
JOIN bannhac bn ON bt.idBannhac = bn.idBannhac
JOIN casi    cs ON bt.idCasi    = cs.idCasi
WHERE bn.tenBannhac = 'Tiến về Hà Nội';

Câu 3LIKE · 1 bảng

Tìm những nhạc sĩ (idNhacsi, tenNhacsi) có họ là Nguyễn.

Bảng liên quan: nhacsi

Xem hướng dẫn giải câu 3

Phân tích

  1. Chỉ cần bảng nhacsi, lấy hai cột idNhacsi, tenNhacsi.
  2. Họ đứng đầu tên → tên phải bắt đầu bằng “Nguyễn”. Dùng LIKE 'Nguyễn%', trong đó % thay cho chuỗi kí tự bất kì (kể cả rỗng).

Câu lệnh SQL

SQL
SELECT idNhacsi, tenNhacsi
FROM nhacsi
WHERE tenNhacsi LIKE 'Nguyễn%';

Câu 7Nối 4 bảng · lọc

Lấy danh sách các bản thu âm với các thông tin: idBanthuam, tenBannhac, tenCasi các bản nhạc của nhạc sĩ Văn Cao.

Bảng liên quan: banthuam, bannhac, casi, nhacsi

Xem hướng dẫn giải câu 7

Phân tích

  1. Cột hiển thị: idBanthuam (banthuam), tenBannhac (bannhac), tenCasi (casi).
  2. Điều kiện theo tenNhacsi (bảng nhacsi) → phải nối thêm bảng thứ tư dù không hiển thị cột nào của nó.
  3. Chuỗi nối: banthuam → bannhac → nhacsi và banthuam → casi.
  4. Lọc ns.tenNhacsi = 'Văn Cao'.

Câu lệnh SQL

SQL
SELECT bt.idBanthuam, bn.tenBannhac, cs.tenCasi
FROM banthuam bt
JOIN bannhac bn ON bt.idBannhac = bn.idBannhac
JOIN nhacsi  ns ON bn.idNhacsi  = ns.idNhacsi
JOIN casi    cs ON bt.idCasi    = cs.idCasi
WHERE ns.tenNhacsi = 'Văn Cao';

Lấy danh sách các bản thu âm với các thông tin idBanthuam, tenBannhac, tenNhacsi, tenCasi các bản nhạc do ca sĩ Lê Dung thể hiện thuộc thể loại Nhạc trữ tình.

Bảng liên quan: banthuam, bannhac, nhacsi, casi

Xem hướng dẫn giải câu 11

Phân tích

  1. Cần cả 4 bảng: bốn cột hiển thị đến từ bốn bảng khác nhau.
  2. Hai điều kiện đồng thời: ca sĩ là Lê Dung và thể loại là Nhạc trữ tình → nối bằng AND.
  3. tenTheloai là cột của bảng bannhac nên dùng bn.tenTheloai.

Câu lệnh SQL

SQL
SELECT bt.idBanthuam, bn.tenBannhac, ns.tenNhacsi, cs.tenCasi
FROM banthuam bt
JOIN bannhac bn ON bt.idBannhac = bn.idBannhac
JOIN nhacsi  ns ON bn.idNhacsi  = ns.idNhacsi
JOIN casi    cs ON bt.idCasi    = cs.idCasi
WHERE cs.tenCasi = 'Lê Dung'
  AND bn.tenTheloai = 'Nhạc trữ tình';

Lê Dung có 2 bản thu âm (mã 2 và 8) nhưng chỉ bản “Trường ca sông Lô” thuộc thể loại Nhạc trữ tình; bản “Tiếng hát giữa rừng Pắc Bó” thuộc Nhạc quê hương nên bị loại. Đây là tác dụng của AND: một dòng phải thoả cả hai điều kiện.

5 Tổng kết

Chọn bảng cho đủLiệt kê mọi bảng chứa cột cần hiển thị hoặc cột dùng để lọc; thêm bảng trung gian nếu hai bảng không nối trực tiếp.
Nối theo khoáMỗi lần JOIN đi kèm một ON: khoá ngoài = khoá chính được tham chiếu. Nối n bảng cần n − 1 điều kiện ON.
Lọc bằng WHEREDùng = cho giá trị chính xác, LIKE + % cho mẫu, AND khi cần thoả đồng thời nhiều điều kiện.
Dùng bí danhbanthuam bt, bannhac bn… giúp câu lệnh gọn và tránh nhầm khi hai bảng có cột trùng tên.
💡

Thứ tự dòng kết quả: nếu không có ORDER BY, máy chủ có thể trả các dòng theo thứ tự khác với bảng mẫu. Điều quan trọng là đủ dòng và đúng giá trị.
