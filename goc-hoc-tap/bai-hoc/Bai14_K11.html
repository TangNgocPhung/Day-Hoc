        Kiến thức chính
        
Lập trình “theo thủ tục” và truy vấn “khai báo”

        

          
Cách 1: người dùng phải biết rõ thủ tục
Phải biết cấu trúc tệp dữ liệu để lập trình lấy ra từng đoạn dữ liệu liên quan tới mỗi bản nhạc. Việc này mất công, dễ nhầm lẫn; bài toán khác (ví dụ lập danh sách học sinh có điểm trung bình môn Toán trên 8) lại phải viết lại chương trình với thủ tục tương tự.

          
Cách 2: người dùng chỉ nêu yêu cầu
Chỉ cần viết ra yêu cầu dưới dạng một câu truy vấn – muốn làm gì, không phải nghĩ cách thực hiện. Hệ QTCSDL tiếp nhận yêu cầu ở dạng xâu truy vấn rồi lấy ra kết quả đúng như yêu cầu.

        

        

          
SQL (Structured Query Language) là ngôn ngữ truy vấn định chuẩn cho việc định nghĩa, cập nhật, truy xuất và điều khiển dữ liệu từ các CSDL quan hệ. SQL được xây dựng từ những năm 1970 và đã trở thành ngôn ngữ truy vấn tiêu chuẩn mà hầu hết các hệ QTCSDL đều sử dụng: Oracle, SQL Server, MySQL, PostgreSQL,…

          Nguồn: SGK Tin học 11, Bài 14, mục 1.
        

        
Điều đó có nghĩa là một câu lệnh SQL viết đúng chuẩn có thể dùng để thao tác trên hầu hết các hệ QTCSDL phổ biến. SQL có ba thành phần:

        

          
DDL
Data Definition Language
Ngôn ngữ định nghĩa dữ liệu: tạo CSDL, bảng, khoá.
  • CREATE DATABASE
  • CREATE TABLE
  • ALTER TABLE

          
DML
Data Manipulation Language
Ngôn ngữ thao tác dữ liệu: truy xuất và cập nhật dữ liệu.
  • SELECT
  • INSERT INTO
  • UPDATE · DELETE FROM

          
DCL
Data Control Language
Ngôn ngữ kiểm soát dữ liệu: quyền của người dùng.
  • GRANT
  • REVOKE

        

        
Trong bài này, em sẽ dùng SQL để minh hoạ cách thức quản trị CSDL âm nhạc gồm bốn bảng: nhacsi, bannhac, casi, banthuam (dữ liệu mẫu giống Bài 13). Lưu ý: SGK ghi nhạc sĩ có Aid = 1 là Văn Cao, còn trong dữ liệu mẫu của bài này Aid = 1 là Đỗ Nhuận; cách làm không thay đổi.

        Ví dụ · Khởi tạo CSDL âm nhạc
        
Khởi tạo CSDL âm nhạc đặt tên là music và khởi tạo các bảng Nhạc sĩ, Bản nhạc có tên tương ứng là nhacsi và bannhac.

        
CREATE DATABASE music;
Khởi tạo CSDL music.

        
CREATE TABLE bannhac (
  Mid CHAR(4),
  Aid INT,
  TenBN VARCHAR(128)
);
Khởi tạo bảng bannhac với ba trường; mỗi trường gồm tên + kiểu dữ liệu, ngăn cách nhau bằng dấu phẩy (trường cuối không có dấu phẩy).

        
ALTER TABLE bannhac ADD PRIMARY KEY (Mid);
Thêm khoá chính Mid cho bảng bannhac bằng câu lệnh thay đổi định nghĩa bảng.

        
CREATE TABLE nhacsi (
  Aid INT,
  TenNS VARCHAR(64)
);
Khởi tạo bảng nhacsi. Dấu chấm phẩy “;” được dùng để kết thúc câu truy vấn.

        
Phòng SQL sẽ tự nạp sẵn CSDL trống.

        Liên kết bảng với INNER JOIN
        
SELECT bannhac.TenBN, nhacsi.TenNS
FROM bannhac INNER JOIN nhacsi
ON bannhac.Aid = nhacsi.Aid;
Chọn tất cả các dòng từ bảng bannhac, liên kết với bảng nhacsi theo khoá Aid; ở mỗi dòng lấy cột TenBN của bảng bannhac và cột TenNS của bảng nhacsi.

            Bảng 14.5. Câu truy vấn kiểm soát quyền người dùng
            
Mẫu câu truy vấnÝ nghĩa

            
GRANTCấp quyền cho người dùng
REVOKEThu hồi quyền đối với người dùng

          

        

        
GRANT select
ON music.*
TO guest;
Cấp quyền dùng truy vấn SELECT đối với tất cả các bảng trong CSDL music cho người dùng guest.

        
REVOKE create, alter
ON music.bannhac
FROM mod;
Thu hồi quyền CREATE và ALTER cho bảng bannhac trong CSDL music đối với người dùng mod.

        
Cách đọc: GRANT quyền ON đối_tượng TO người_dùng và REVOKE quyền ON đối_tượng FROM người_dùng. Đối tượng music.* là mọi bảng của CSDL music; music.bannhac chỉ là bảng bannhac.

  1. Hãy viết câu truy vấn tạo bảng Bản thu âm (banthuam) như đã mô tả trong Bài 13.
    2. 
          
  2. Viết câu truy vấn tạo khoá ngoài Mid và Sid cho bảng banthuam.
    3. 
          
  3. Viết câu truy vấn lấy ra tất cả các dòng trong liên kết bảng banthuam với bảng bannhac, mỗi dòng lấy các cột: Mid, Sid của bảng banthuam và cột TenBN của bảng bannhac.
    4. 
        

        
        
CREATE TABLE banthuam (
  Mid CHAR(4),
  Sid CHAR(2)
);
ALTER TABLE banthuam ADD FOREIGN KEY (Mid) REFERENCES bannhac(Mid);
ALTER TABLE banthuam ADD FOREIGN KEY (Sid) REFERENCES casi(Sid);

SELECT banthuam.Mid, banthuam.Sid, bannhac.TenBN
FROM banthuam INNER JOIN bannhac
ON banthuam.Mid = bannhac.Mid;

        
Vận dụng

        
Viết câu truy vấn lấy ra tất cả các dòng trong liên kết bảng banthuam với bảng bannhac và bảng casi, mỗi dòng lấy các cột: Mid, Sid của bảng banthuam, cột TenBN của bảng bannhac và cột TenCS của bảng casi.

Tổng kết kiến thức
SQL cho phép “nói điều mình muốn” với CSDL quan hệ.

      

        
Truy vấn khai báoChỉ nêu muốn làm gì; hệ QTCSDL lo cách làm.

        
DDLCREATE DATABASE, CREATE TABLE, ALTER TABLE, khoá chính, khoá ngoài.

        
DMLSELECT (FROM, WHERE, ORDER BY, INNER JOIN), INSERT, DELETE, UPDATE.

        
DCLGRANT cấp quyền, REVOKE thu hồi quyền.

        
Khi viết lệnhKết thúc bằng “;”, nhớ WHERE khi xoá hoặc sửa.

      

      

        
Điểm luyện tập: Chưa hoàn thành

        
Hãy hoàn thành 8 câu luyện tập để cập nhật kết quả tại đây.

      

      

        
Tự đánh giá
Em đã làm được gì?
  • Giải thích lợi ích của ngôn ngữ truy vấn so với lập trình theo thủ tục.
  • Phân biệt DDL, DML, DCL.
  • Tạo CSDL, bảng, khoá chính và khoá ngoài bằng SQL.
  • Truy xuất dữ liệu bằng SELECT, WHERE, ORDER BY, INNER JOIN.
  • Thêm, xoá, sửa dữ liệu; cấp và thu hồi quyền.

        
Vận dụng
CSDL điểm của lớp em
Hãy nghĩ một câu truy vấn để lập danh sách các học sinh có điểm trung bình môn Toán trên 8 từ bảng diemtoan_11A. So với việc viết chương trình duyệt từng dòng, em thấy SQL thuận tiện hơn ở điểm nào?
Gợi ý: dùng SELECT … FROM diemtoan_11A WHERE tb > 8; – thử trong phòng SQL với bộ dữ liệu “Đầy đủ 4 bảng”.
