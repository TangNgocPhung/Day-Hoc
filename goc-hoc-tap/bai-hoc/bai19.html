1. Khởi động

Sau bài này em sẽ:

  • Biết và trình bày được các phép toán với kiểu dữ liệu lôgic.
  • Sử dụng được lệnh rẽ nhánh if trong lập trình.

Trong cuộc sống, chúng ta vẫn thường gặp các tình huống một việc được thực hiện hay không phụ thuộc vào một điều kiện. Ví dụ, em dự định: nếu ngày mai trời không mưa em sẽ đi chơi cùng bạn, ngược lại nếu trời mưa em sẽ ở nhà làm bài tập. Các tình huống như vậy trong lập trình được gọi là rẽ nhánh.

Khởi động

Em hãy điền thông tin ở tình huống trên vào vị trí <Điều kiện> và các lệnh tương ứng trong sơ đồ cấu trúc rẽ nhánh ở Hình 19.1.

Nhận xét. Ô <Điều kiện> luôn là một câu có thể trả lời Đúng hoặc Sai (“Trời không mưa” — đúng hay sai?). Còn “Đi chơi cùng bạn”, “Ở nhà làm bài tập” là việc cần làm (lệnh), không thể đúng/sai. Trong lập trình, <Điều kiện> được viết bằng một biểu thức lôgic — nội dung của phần tiếp theo.

2. Biểu thức lôgic SGK mục 1

Hoạt động 1 · Khái niệm biểu thức lôgic

Biểu thức nào sau đây có thể đưa vào vị trí <điều kiện> trong lệnh Nếu <điều kiện> thì <lệnh> của các ngôn ngữ lập trình bậc cao? (Có thể chọn nhiều phương án.)

Trong Python, biểu thức lôgic là biểu thức chỉ nhận giá trị True (đúng) hoặc False (sai). Biểu thức lôgic đơn giản nhất là các biểu thức so sánh số hoặc xâu kí tự. Trong Hoạt động 1, các phương án B, C, D là biểu thức lôgic.

Quan sát các lệnh sau để nhận biết kiểu dữ liệu lôgic:

>>> a,b,s = 10,2,"Number"     # gán a = 10, b = 2, s = "Number"
>>> a > 10
False                        # a > 10 là sai
>>> b < 3
True                         # b < 3 là đúng
>>> s == "number"
False                        # "Number" và "number" là hai xâu khác nhau

2.1. Các phép so sánh

Chú ý: Với xâu kí tự cũng có đầy đủ các phép so sánh trên (sẽ học sau).

Dễ nhầm: = là lệnh gán (đưa giá trị vào biến), còn == là phép so sánh bằng (hỏi “có bằng nhau không?”). Viết if a = 5: là lỗi cú pháp; phải viết if a == 5:.

2.2. Các phép toán lôgic: and, or, not

Các phép toán trên kiểu dữ liệu lôgic gồm and (và), or (hoặc) và not (phủ định):

  • X and Y chỉ đúng khi cả hai X, Y cùng đúng.
  • X or Y chỉ sai khi cả hai X, Y cùng sai.
  • not X cho giá trị ngược lại với X.

Ví dụ. Cho các lệnh sau, dự đoán giá trị của các biến lôgic a, b, c.

>>> x, y, z = 10, 5, 9
>>> b = x < 11 and z > 5
>>> c = x > 15 or y < 9
>>> a = not b

Tự dự đoán trước, sau đó mới bấm để xem lời giải từng bước.

  • Biểu thức lôgic là biểu thức chỉ nhận giá trị True hoặc False. Giá trị các biểu thức lôgic thuộc kiểu bool.
  • Các phép toán trên kiểu dữ liệu lôgic là and (và), or (hoặc) và not (phủ định).
Câu hỏi

Mỗi biểu thức sau có giá trị True hay False?

Mở rộng — thứ tự thực hiện. Trong một biểu thức, Python tính các phép số học (+ - * / // %) trước, rồi đến phép so sánh, sau cùng là phép lôgic theo thứ tự not → and → or. Khi không chắc, hãy dùng dấu ngoặc: (0 <= x and x <= 1) or (5 <= x and x <= 10).

3. Lệnh if SGK mục 2

Hoạt động 2 · Cấu trúc lệnh if trong Python

Cho trước số tự nhiên n (được gán hoặc nhập từ bàn phím). Đoạn chương trình sau kiểm tra n > 0 thì thông báo "n là số lớn hơn 0".

if n > 0:
    print("n là số lớn hơn 0")

Em có nhận xét gì về cấu trúc lệnh if? Sau <điều kiện> lệnh if có kí tự gì? Lệnh print() được viết như thế nào?

  • Dòng if gồm: từ khoá if, một biểu thức lôgic (n > 0) và kết thúc bằng dấu hai chấm :.
  • Lệnh print() không viết thẳng dưới chữ if mà được viết lùi vào (mặc định 1 tab hay 4 dấu cách). Nhờ lùi vào, Python biết lệnh này thuộc về lệnh if: chỉ chạy khi điều kiện đúng.

Để xử lí các tình huống rẽ nhánh, giống như các ngôn ngữ lập trình khác, Python cũng có các câu lệnh để mô tả cấu trúc rẽ nhánh.

3.1. Câu lệnh điều kiện dạng thiếu

if <điều kiện>:
    <khối lệnh>
  • Sau điều kiện cần có dấu hai chấm :.
  • Khối lệnh tiếp theo cần viết lùi vào và thẳng hàng, mặc định là 1 tab hay 4 dấu cách.

Khi thực hiện lệnh, Python sẽ kiểm tra <điều kiện>, nếu đúng thì thực hiện <khối lệnh>, ngược lại thì bỏ qua, chuyển sang lệnh tiếp theo sau lệnh if.

Mô phỏng: chương trình chạy theo nhánh nào?if dạng thiếu
Thử n = 7, rồi n = 0, n = -4.

3.2. Câu lệnh điều kiện dạng đủ

if <điều kiện>:
    <khối lệnh 1>
else:
    <khối lệnh 2>
  • Từ khoá if và else cần viết thẳng lề trái.
  • Các khối lệnh 1 và khối lệnh 2 cần viết lùi vào và thẳng hàng, mặc định là 1 tab hay 4 dấu cách.

Khi thực hiện lệnh, Python sẽ kiểm tra <điều kiện>, nếu đúng thì thực hiện <khối lệnh 1>, ngược lại thì thực hiện <khối lệnh 2>.

Ví dụ, nếu a, b là hai số đã được tạo thì lệnh sau sẽ in ra giá trị tuyệt đối của hiệu hai số:

if a > b:
    print(a - b)
else:
    print(b - a)
Mô phỏng: giá trị tuyệt đối của hiệu hai sốif dạng đủ

Dù chạy theo nhánh nào, kết quả in ra luôn là số không âm. Khi a = b thì điều kiện a > b sai, chương trình in b - a = 0.

Chú ý. Các khối lệnh trong Python đều cần viết sau dấu : và lùi vào, thẳng hàng. Đây là điểm khác biệt của Python với các ngôn ngữ lập trình khác.

Câu lệnh điều kiện if thể hiện cấu trúc rẽ nhánh trong Python. Khối lệnh rẽ nhánh của if được viết sau dấu :, cần viết lùi vào và thẳng hàng.

Luyện mắt: tìm dòng viết sai

Mỗi đoạn chương trình dưới đây có đúng một dòng sai cú pháp. Em hãy bấm vào dòng đó.

3.3. Lệnh if lồng nhau

Khối lệnh bên trong if hoặc else có thể chứa một lệnh if khác. Cách viết này dùng khi có nhiều hơn hai trường hợp, như ở Nhiệm vụ 2 phần Thực hành. Ví dụ, xếp loại một số nguyên n thành ba trường hợp:

if n > 0:
    print("n là số dương")
else:
    if n == 0:                 # lệnh if nằm trong khối else
        print("n bằng 0")
    else:
        print("n là số âm")

Lệnh if bên trong được lùi vào một mức; các khối lệnh của nó lại lùi thêm một mức nữa.

Câu hỏi

Đoạn chương trình sau thực hiện công việc gì?

k = int(input("Nhập một số nguyên dương: "))
if k <= 0:
    print("Bạn nhập sai rồi!")

Chương trình yêu cầu nhập một số nguyên dương k. Nếu người dùng nhập số không dương (k <= 0, ví dụ 0 hoặc -3) thì máy in ra thông báo Bạn nhập sai rồi!; nếu nhập đúng số dương thì không in gì.

Đây là lệnh if dạng thiếu, dùng để kiểm tra dữ liệu nhập vào có hợp lệ không.

4. Thực hành

Các bài tập liên quan đến kiểu dữ liệu bool và lệnh if.

Nhiệm vụ 1

Viết chương trình nhập số tự nhiên n từ bàn phím. Sau đó thông báo số em đã nhập là số chẵn hay số lẻ phụ thuộc vào n là chẵn hay lẻ.

Hướng dẫn. Để kiểm tra một số tự nhiên n là chẵn hay lẻ, ta dùng phép toán lấy số dư n%2. Nếu số dư bằng 0 thì n là số chẵn, ngược lại n là số lẻ. Chương trình có thể như sau:

n = int(input("Nhập số tự nhiên n: "))
if n%2 == 0:
    print("Số đã nhập là số chẵn.")
else:
    print("Số đã nhập là số lẻ.")

Bộ kiểm thử — chạy chương trình với từng dữ liệu vào và so sánh kết quả:

Nhiệm vụ 2

Giả sử giá điện sinh hoạt trong khu vực gia đình em ở được tính luỹ kế theo từng tháng như sau (giá tính theo từng kWh điện tiêu thụ):

  • Với mức điện tiêu thụ từ 0 đến 50 kWh, giá thành mỗi kWh là 1,678 nghìn đồng.
  • Với mức từ 51 đến 100, giá thành mỗi kWh là 1,734 nghìn đồng.
  • Từ mức 101 trở lên, giá thành mỗi kWh là 2,014 nghìn đồng.

Viết chương trình nhập số điện tiêu thụ trong tháng của gia đình em và tính số tiền điện phải trả.

Hướng dẫn. Gọi k là số kWh điện tiêu thụ của gia đình em. Khi đó theo cách tính luỹ kế trên chúng ta cần tính dựa trên các điều kiện sau:

  • Nếu k ≤ 50 thì số tiền cần trả là k × 1,678 nghìn đồng.
  • Nếu 50 < k ≤ 100 thì số tiền cần trả là 50 × 1,678 + (k − 50) × 1,734 nghìn đồng.
  • Nếu 100 < k thì số tiền cần trả là 50 × 1,678 + 50 × 1,734 + (k − 100) × 2,014 nghìn đồng.

Chúng ta sử dụng lệnh round(t) để làm tròn số thực t. Chú ý trong máy tính dùng dấu . để viết các số thập phân. Chương trình có thể như sau:

k = float(input("Nhập số kWh tiêu thụ điện nhà em: "))
if k<= 50:
    t = k*1.678
else:
    if k <= 100:
        t = 50*1.678 + (k-50)*1.734
    else:
        t = 50*1.678 + 50*1.734 + (k-100)*2.014
print("Số tiền điện phải trả là:",round(t), "nghìn đồng")

Hiểu “luỹ kế”: không phải toàn bộ số điện tính theo một giá. 50 kWh đầu tính giá bậc 1, 50 kWh tiếp theo tính giá bậc 2, phần còn lại tính giá bậc 3. Kéo thanh trượt để xem:

5. Luyện tập SGK trang 104

Bài 1

Viết biểu thức lôgic ứng với mỗi câu sau:

  1. Số x nằm trong khoảng (0; 10).
  2. Số y nằm ngoài đoạn [1; 2].
  3. Số z nằm trong đoạn [0; 1] hoặc [5; 10].

Gợi ý: khoảng ( ) không lấy hai đầu mút → dùng <; đoạn [ ] có lấy hai đầu mút → dùng <=.

a) 0 < x and x < 10

b) y < 1 or y > 2 (hoặc not (1 <= y and y <= 2))

Nằm ngoài đoạn [1; 2] thì y không thể vừa nhỏ hơn 1 vừa lớn hơn 2, nên phải dùng or, không dùng and.

c) (0 <= z and z <= 1) or (5 <= z and z <= 10)

Chấm rỗng: không lấy đầu mút; chấm đặc: có lấy đầu mút. Python còn cho phép viết gọn 0 < x < 10, nhưng cách viết với and như trên dùng được trong mọi ngôn ngữ lập trình.

Bài 2

Tìm một vài giá trị m, n thoả mãn các biểu thức sau:

  1. 100%m == 0 and n%5 != 0
  2. m%100 == 0 and m%400 != 0
  3. n%3 == 0 or (n%3 != 0 and n%4 == 0)
Máy kiểm tra: nhập m, n em tìm được

a) m là ước của 100 (1, 2, 4, 5, 10, 20, 25, 50, 100) và n không chia hết cho 5. Ví dụ: m = 20, n = 7; m = 4, n = 12. Chú ý: m = 0 gây lỗi chia cho 0.

b) m chia hết cho 100 nhưng không chia hết cho 400: m = 100, 200, 300, 500, 1900… (Đây chính là những năm tròn thế kỉ không nhuận!)

c) n chia hết cho 3, hoặc không chia hết cho 3 nhưng chia hết cho 4 — tức là n chia hết cho 3 hoặc cho 4: n = 3, 4, 6, 8, 9, 12, 15, 16…

6. Vận dụng SGK trang 104

Hãy tự viết chương trình trước. Bấm Nạp khung bài để có sẵn phần nhập dữ liệu trong Phòng thực hành, rồi viết tiếp phần còn thiếu.

Vận dụng 1

Giá bán cam tại siêu thị tính như sau: nếu khối lượng cam mua dưới 5 kg thì giá bán là 12 000 đồng/kg, nếu khối lượng mua lớn hơn hoặc bằng 5 kg thì giá bán là 10 000 đồng/kg. Viết chương trình nhập số lượng mua (tính theo kg) sau đó tính số tiền phải trả.

Phân tích. Dữ liệu vào: khối lượng m (số thực). Điều kiện rẽ nhánh: m < 5. Hai nhánh chỉ khác nhau ở đơn giá.

m = float(input("Nhập khối lượng cam (kg): "))
# Viết lệnh if ... else để tính số tiền t

print("Số tiền phải trả là:", t, "đồng")
m = float(input("Nhập khối lượng cam (kg): "))
if m < 5:
    t = m*12000
else:
    t = m*10000
print("Số tiền phải trả là:", t, "đồng")

Kiểm thử: m = 4 → 48000.0 đồng; m = 5 → 50000.0 đồng; m = 4.5 → 54000.0 đồng.

Suy nghĩ thêm: mua 4,5 kg phải trả 54 000 đồng, nhiều hơn mua 5 kg (50 000 đồng)! Nếu là người mua, em sẽ làm gì?

Vận dụng 2

Năm n là năm nhuận nếu giá trị n thoả mãn điều kiện: n chia hết cho 400 hoặc n chia hết cho 4 đồng thời không chia hết cho 100. Viết chương trình nhập số năm n và cho biết năm n có phải là năm nhuận hay không.

Phân tích. Chuyển từng cụm từ của đề thành biểu thức: “chia hết cho 400” → n%400 == 0; “chia hết cho 4” → n%4 == 0; “không chia hết cho 100” → n%100 != 0; “đồng thời” → and; “hoặc” → or.

n = int(input("Nhập năm n: "))
# Viết lệnh if ... else kiểm tra n có phải năm nhuận không

n = int(input("Nhập năm n: "))
if n%400 == 0 or (n%4 == 0 and n%100 != 0):
    print("Năm", n, "là năm nhuận.")
else:
    print("Năm", n, "không phải là năm nhuận.")

8. Bài tập bổ sung (19.1 – 19.12)

Các bài tập rèn luyện thêm, tăng dần độ khó. Mỗi bài có gợi ý và chương trình tham khảo; hãy tự làm trước khi xem.

19.1. Viết biểu thức lôgic tương ứng

  1. Số x nhỏ hơn 50.
  2. Số x nằm trong khoảng (50; 100].
  3. Số x nằm trong đoạn [0; 50] hoặc lớn hơn 100.

a) x < 50   b) 50 < x and x <= 100   c) (0 <= x and x <= 50) or x > 100

19.2. Tìm giá trị m, n thoả mãn

  1. 50%m == 0 and n%4 != 0
  2. m%100 == 0 and m%400 != 0
  3. n%5 == 0 or (n%5 != 0 and n%3 == 0)

a) m là ước của 50 (1, 2, 5, 10, 25, 50), n không chia hết cho 4: ví dụ m = 5, n = 3.
b) m = 100, 200, 300, 500…
c) n chia hết cho 5 hoặc cho 3: n = 3, 5, 6, 9, 10…

19.3. Viết biểu thức điều kiện

  1. m chia hết cho 100 nhưng không chia hết cho 400.
  2. x có giá trị không thuộc đoạn [0; 2].
  3. x có giá trị thuộc khoảng (2; 4) hoặc thuộc khoảng (5; 6).

a) m%100 == 0 and m%400 != 0
b) x < 0 or x > 2 (hoặc not (0 <= x and x <= 2))
c) (2 < x and x < 4) or (5 < x and x < 6)

19.4. Xác định giá trị của a, b, c sau khi thực hiện các lệnh

a, b, c = 1, 2, 3
a = (a < b) and (b < c)
b = (b < c) or (c%b == 0)
c = c%2 != 0
  • Dòng 2: 1 < 2 đúng, 2 < 3 đúng → a = True.
  • Dòng 3: lúc này b = 2, c = 3; 2 < 3 đúng → b = True (với or chỉ cần một vế đúng).
  • Dòng 4: 3%2 = 1, 1 != 0 đúng → c = True.

Kết quả: a = True, b = True, c = True. Chú ý các lệnh chạy lần lượt: khi tính b, biến a đã đổi nhưng biểu thức của b không dùng a.

19.5. Số chẵn hay số lẻ

Viết câu lệnh điều kiện để in ra các thông báo tương ứng tuỳ theo giá trị của số nguyên n là số chẵn hay số lẻ.

Giống Nhiệm vụ 1 phần Thực hành: điều kiện n%2 == 0. Với số nguyên âm, Python vẫn cho -7%2 = 1 nên chương trình vẫn đúng.

19.7. Chỉ số BMI

Chỉ số BMI (Body Mass Index) được tính bằng cân nặng (kg) chia cho bình phương chiều cao (m), cho biết tình trạng cân nặng của người trưởng thành (trên 18 tuổi). Với người trưởng thành châu Á:

BMIPhân loại
< 18,5Thiếu cân
18,5 – 22,9Bình thường
≥ 23Thừa cân

Em hãy viết chương trình tính chỉ số BMI của một người và đưa ra thông báo tương ứng.

m = float(input("Cân nặng (kg): "))
h = float(input("Chiều cao (m): "))
bmi = m/(h*h)
print("BMI =", round(bmi, 1))
if bmi < 18.5:
    print("Thiếu cân")
else:
    if bmi < 23:
        print("Bình thường")
    else:
        print("Thừa cân")

19.8. Khuyến mại mua cam

Để khuyến khích tiêu thụ cam, một chủ vườn đưa ra chính sách: nếu số cam mua lớn hơn 10 kg thì đơn giá của phần vượt quá 10 kg chỉ bằng 90% đơn giá của 10 kg đầu tiên. Em hãy viết chương trình tính số tiền mua cam phải trả với đơn giá và số cam mua được nhập từ bàn phím.

p = float(input("Đơn giá (đồng/kg): "))
x = float(input("Số kg cam mua: "))
if x <= 10:
    t = x*p
else:
    t = 10*p + (x-10)*p*0.9
print("Số tiền phải trả:", t, "đồng")

Tính luỹ kế giống Nhiệm vụ 2: chỉ phần vượt 10 kg mới được giảm giá.

19.9. Ba cạnh của tam giác

Em hãy viết chương trình nhập ba số thực dương a, b, c, kiểm tra xem ba số đó có thể là độ dài các cạnh của một tam giác hay không, nếu có thì tính chu vi, diện tích của tam giác đó.

Ba số là ba cạnh tam giác khi tổng hai số bất kì lớn hơn số còn lại. Diện tích tính theo công thức Heron: S = √(p(p−a)(p−b)(p−c)) với p là nửa chu vi.

a = float(input("a = "))
b = float(input("b = "))
c = float(input("c = "))
if a+b > c and a+c > b and b+c > a:
    p = (a+b+c)/2
    s = (p*(p-a)*(p-b)*(p-c))**0.5
    print("Chu vi:", a+b+c)
    print("Diện tích:", round(s, 2))
else:
    print("Ba số đã nhập không phải ba cạnh của tam giác.")

19.10. Phương trình bậc nhất

Em hãy viết chương trình giải phương trình bậc nhất dạng tổng quát ax + b = c, các hệ số a, b, c là các số thực được nhập vào từ bàn phím.

Phương trình tương đương ax = c − b. Nếu a ≠ 0: một nghiệm. Nếu a = 0: vô số nghiệm khi b = c, vô nghiệm khi b ≠ c.

a = float(input("a = "))
b = float(input("b = "))
c = float(input("c = "))
if a != 0:
    print("Nghiệm x =", (c-b)/a)
else:
    if b == c:
        print("Phương trình có vô số nghiệm.")
    else:
        print("Phương trình vô nghiệm.")

19.11. Phương trình bậc hai

Em hãy viết chương trình giải phương trình bậc hai dạng tổng quát ax² + bx + c = 0 (a khác 0), các giá trị a, b, c là các số thực được nhập vào từ bàn phím.

a = float(input("a = "))
b = float(input("b = "))
c = float(input("c = "))
d = b*b - 4*a*c
if d < 0:
    print("Phương trình vô nghiệm.")
else:
    if d == 0:
        print("Nghiệm kép x =", -b/(2*a))
    else:
        x1 = (-b + d**0.5)/(2*a)
        x2 = (-b - d**0.5)/(2*a)
        print("x1 =", x1, "; x2 =", x2)

19.12. Tiền điện theo đơn giá bậc thang

Đơn giá 1 áp dụng cho 50 kWh đầu tiên; đơn giá 2 cho mỗi kWh từ 51 tới 100; đơn giá 3 cho mỗi kWh từ 101 tới 200; đơn giá 4 cho mỗi kWh từ 201 trở đi. Đơn giá và lượng điện tiêu thụ là các số nguyên được nhập vào từ bàn phím. Em hãy viết chương trình tính tiền điện phải nộp.

Mở rộng Nhiệm vụ 2 thành bốn bậc bằng cách lồng thêm một lệnh if:

d1 = int(input("Đơn giá 1: "))
d2 = int(input("Đơn giá 2: "))
d3 = int(input("Đơn giá 3: "))
d4 = int(input("Đơn giá 4: "))
k = int(input("Số kWh tiêu thụ: "))
if k <= 50:
    t = k*d1
else:
    if k <= 100:
        t = 50*d1 + (k-50)*d2
    else:
        if k <= 200:
            t = 50*d1 + 50*d2 + (k-100)*d3
        else:
            t = 50*d1 + 50*d2 + 100*d3 + (k-200)*d4
print("Tiền điện phải nộp:", t)

Mở rộng — elif. Python có từ khoá elif (viết tắt của else if) để tránh lồng quá sâu. Phần if ở trên có thể viết thẳng hàng như sau, kết quả không đổi:

if k <= 50:
    t = k*d1
elif k <= 100:
    t = 50*d1 + (k-50)*d2
elif k <= 200:
    t = 50*d1 + 50*d2 + (k-100)*d3
else:
    t = 50*d1 + 50*d2 + 100*d3 + (k-200)*d4

9. Tổng kết bài học

Hoàn thành phần Trắc nghiệm để xem điểm số của em!

Biểu thức lôgic

  • Chỉ nhận giá trị True hoặc False, kiểu bool.
  • So sánh: < <= > >= == !=
  • Lôgic: and đúng khi cả hai đúng; or sai khi cả hai sai; not đảo giá trị.

Lệnh if dạng thiếu

if <điều kiện>:
    <khối lệnh>

Điều kiện sai → bỏ qua khối lệnh.

Lệnh if dạng đủ

if <điều kiện>:
    <khối lệnh 1>
else:
    <khối lệnh 2>

Luôn thực hiện đúng một trong hai khối.

3 lỗi hay gặp

  • Quên dấu : sau điều kiện hoặc sau else.
  • Không lùi lề khối lệnh, hoặc else không thẳng hàng với if.
  • Viết = thay cho == trong điều kiện.
