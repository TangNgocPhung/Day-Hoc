Hàm là chương trình con

Một hàm gói các lệnh để làm một công việc. Khi cần thực hiện công việc đó, ta gọi hàm bằng tên.

Python cung cấp nhiều hàm có sẵn; em cũng có thể tạo hàm riêng bằng def.

Cùng có dấu ngoặc sau tên, nhưng print(), len() và int() thực hiện những công việc khác nhau.

NHIỆM VỤ 2 & VẬN DỤNG 1
Hàm prime(n): một kết quả, hai cách viết
Số nguyên tố là số tự nhiên lớn hơn 1 chỉ có hai ước dương là 1 và chính nó. Nhập n để theo dõi cách đếm ước trong sách và cách thoát sớm bằng return.
A / Đếm các ước thực sự
def prime(n):
    C = 0
    k = 1
    while k < n:
        if n % k == 0:
            C = C + 1
        k = k + 1
    if C == 1:
        return True
    else:
        return False
Ước thực sự là ước dương nhỏ hơn n. Khi C = 1, ước thực sự duy nhất là 1.
B / Dừng ngay khi tìm thấy ước
def prime(n):
    if n < 2:
        return False
    k = 2
    while k < n:
        if n % k == 0:
            return False
        k = k + 1
    return True
n < 2: trả False ngay. Có ước trong khoảng 2 đến n − 1: trả False ngay. Nếu không, trả True.

LUYỆN TẬP 1

Gợi ý và mã Python
def prime(n):
    if n < 2:
        return False
    k = 2
    while k < n:
        if n % k == 0:
            return False
        k = k + 1
    return True

def uoc_nguyen_to(n):
    for k in range(2, n + 1):
        if n % k == 0 and prime(k):
            print(k, end=" ")

n = int(input("Nhập số tự nhiên dương n: "))
uoc_nguyen_to(n)
In mỗi ước nguyên tố một lần. n = 1 không có ước nguyên tố. Mã giả sử n là số tự nhiên dương.


LUYỆN TẬP 2 & VẬN DỤNG 2
Đếm chữ số và chữ cái tiếng Anh
Trong phần minh họa này: chữ số là 0–9; chữ cái tiếng Anh là A–Z và a–z. Dấu cách, dấu câu, chữ có dấu không thuộc hai nhóm đó.
Xem hai hàm Python
def numbers(s):
    dem = 0
    for ch in s:
        if "0" <= ch <= "9":
            dem = dem + 1
    return dem

def letters(s):
    dem = 0
    for ch in s:
        if "A" <= ch <= "Z" or "a" <= ch <= "z":
            dem = dem + 1
    return dem

s = input("Nhập xâu: ")
print("Số kí tự chữ số:", numbers(s))
print("Số chữ cái tiếng Anh:", letters(s))
Ví dụ trong sách: numbers("0101abc") = 4.
